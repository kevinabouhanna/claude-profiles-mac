# Phase 1: The app

**Milestone:** Phase 1: The app · **Status:** Done

**Goal:** every Claude Code account's usage in the menu bar, and one-click switching between
them, light on the battery.

## What shipped

- Usage in the menu bar, and a dropdown with each account's session and weekly usage, pace and
  resets (#19); tabs to look at an account without using it, and a status bar with a Switch menu
  to use it (#25, #26).
- Accounts reordered, two Switch Account options (#13); per-model limits hidden by default
  (#23); an expired sign-in explained in words (#21); the menu bar's colours on the dropdown's
  numbers (#9); Settings tidied (#7, #12).
- README pictures that redraw themselves (#28), and its pitch and requirement written once (#38).
